Deployment checklist
  1. Serve this exact file at an HTTPS URL, as the top-level page.
  2. Do not send Permissions-Policy: camera=(). A top-level app normally needs Permissions-Policy: camera=(self), or no restrictive camera policy.
  3. If embedding is unavoidable, the host header must delegate to the embedded origin and its iframe must include allow="camera". Sandboxed frames also need allow-same-origin.
  4. Open the same URL in Safari/Chrome's normal browser, not an in-app preview. If it works there but not in the preview, the host app/webview must add native camera and motion permission handling; website settings cannot override that.
  5. On iOS, enable Camera for the browser/host app in Settings and check that site's camera setting. On Android Chrome, check the Chrome app camera permission and the site's permission.
